# Base histórica Google Sheets

1. Abra a planilha compartilhada e crie um projeto Apps Script vinculado a ela.
2. Cole `Code.gs`.
3. Implante como aplicativo da Web, executando como o proprietário e com acesso para quem utilizar o sistema.
4. Use a URL `/exec` do aplicativo na configuração do sistema.

O endpoint apenas acrescenta linhas na aba `Registros`; não apaga nem altera o histórico.
